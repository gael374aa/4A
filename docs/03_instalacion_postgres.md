# 3. Instalación de PostgreSQL

Para realizar la correcta instalación del sistema de gestión de base de datos llamado "PostgreSQL" es necesario seguir una serie de pasos. 
El primer paso se encuentra de manera implícita, que es el descargar el sistema de la pagina oficial, una vez que se realice este paso, 
se continua ahora si con la configuración y cada uno de los pasos a seguir una vez que se empiece a inicializar el sistema de instalación de este "recurso".

<div align="center">
  <figure>
    <img src="https://raw.githubusercontent.com/TU_USUARIO/TU_REPOSITORIO/main/4A/assets/1_instalacion.png" alt="Instalación de PostgreSQL" width="70%">
    <figcaption><em>Figura 1: Proceso de instalación y bienvenida de PostgreSQL.</em></figcaption>
  </figure>
</div>

Lo primero que se nos presenta en la imagen, es la primera pantalla del instalador que viene incluido al descargar postgreSQL, en el cual, 
solo nos da la bienvenida al sistema. Una vez que pasamos a esta pantalla principal, se dio clic en el boton "siguente".

<div align="center">
  <img src="/4A/assets/1_rurta.png" alt="ruta de instalación" width="50%">
</div>

Como siguiente paso, se requirió indicar una ruta del directorio en la cual se guardara e instalará dicho sistema. Aquí podemos escribir 
directamente la ruta o con ayuda del botón que se encuentra a un lado, podremos seleccionar directamente de manera sencilla la carpeta 
donde queremos que se instale.

<div align="center">
  <img src="/4A/assets/1_componentes.png" alt="selección de componentes" width="50%">
</div>

Una vez que se indicó la ruta de instalación, el siguiente pasó fue seleccionar los componentes que requerimos en su uso. Este paso nos permite 
elegir qué módulos o herramientas adicionales instalar en el sistema marcando o desmarcando sus casillas. Lo recomendado para un uso general del sistema, 
es dejar marcadas todas las casillas.

<div align="center">
  <img src="/4A/assets/2_rurtadatos.png" alt="ruta de guardado" width="50%">
</div>

En esta siguiente pantalla, se nos presentó la selección de la ruta en la cual se irán guardando cada una de las bases de datos creadas en el sistema, 
de igual manera, lo podemos elegir directamente una carpeta desde nuestro administrador de archivos con la ayuda del botón que se encuentra a un costado.

<div align="center">
  <img src="/4A/assets/1_seguridad.png" alt="creación de contraseña" width="50%">
</div>

El siguiente paso fue crear una contraseña, en este caso que solo es para uso escolar, no hay tanta seguridad en la contraseña,
pero para crear una base de datos de un negocio o empresa, es necesario establecer una contraseña lo suficientemente segura.

<div align="center">
  <img src="/4A/assets/1_puerto.png" alt="selección de puerto" width="50%">
</div>

El puerto es mediante el cual el servidor escucha y acepta conexiones entrantes de clientes o aplicaciones.  Este puerto actúa como el punto final 
virtual para la comunicación TCP/IP, permitiendo que las herramientas de base de datos se conecten al servicio de manera local o remota. Por predeterminado viene el "5432" y e este caso, lo dejamos así.

<div align="center">
  <img src="/4A/assets/1_adicionales.png" alt="configuración regional" width="50%">
</div>

En esta siguiente imagen se aprecia una de las opciones avanzadas, prácticamente de los últimos pasos para finalizar la instalación, en este apartado únicamente se configura una configuración regional, que nuevamente, se quedara con los parámetros default que establece el instalador.

<div align="center">
  <img src="/4A/assets/1_configuracionusada.png" alt="configuración usada" width="50%">
</div>

Este apartado nos mostró la configuración que va a ser usada a la hora de dar click en finalizar la instalación, por decirle de una manera, es solo 
para confirmar parámetros y rutas de directorios.

<div align="center">
  <img src="/4A/assets/1_instalacionconfirmacion.png" alt="confirmación de intalación" width="50%">
</div>

Una de las ultimas pantallas, en la cual al dar clic en siguiente, el instalador empezará de manera automatica la instalación 
del sistema con dichas especificaciones establecidas por nosotros.

<div align="center">
  <img src="/4A/assets/1_procesoinstalacion.png" alt="proceso de instalación" width="50%">
</div>

La barra muestra el porcentaje de avance al momento de instalar, este proceso puede tardar algunos minutos, todo depende de los componentes
y capacidad del equipo de computo en el cual estamos realizando la instalación del sistema.

<div align="center">
  <img src="/4A/assets/1_finalizacion.png" alt="instalación hecha" width="50%">
</div>

Muestra una ventana en la cual solo nos indica la confirmación de que el sistema fue instalado en nuestro equipo de computo, como siguiente, se dio clic en el botón de "terminar".

<div align="center">
  <img src="/4A/assets/1_terminodeinstalar.png" alt="instalación terminada" width="50%">
</div>

Esta pantalla corresponde a la fase final del asistente de instalación de PostgreSQL en Windows, confirmando que la instalación básica se ha completado correctamente en el sistema. En caso de que lo requieras, si marcas la casilla que se muestra en la imagen, te redirigirá a una ventana mas, esto para instalar 
controladores adicionales que necesites.
