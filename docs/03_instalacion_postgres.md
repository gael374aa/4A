# 3. Instalación de PostgreSQL

Para realizar la correcta instalación del sistema de gestión de base de datos llamado "PostgreSQL" es necesario seguir una serie de pasos. El primer paso se encuentra de manera implícita, que es el descargar el sistema de la pagina oficial, una vez que se realice este paso, se continua ahora si con la configuración y cada uno de los pasos a seguir una vez que se empiece a inicializar el sistema de instalación de este "recurso".
