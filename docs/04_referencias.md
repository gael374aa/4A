# 4. Conclusiones

La realización de esta práctica permitió conocer y llevar a cabo el proceso de instalación, configuración y verificación de dos Sistemas Gestores de Bases de Datos Relacionales ampliamente utilizados: **MySQL y PostgreSQL**. A través de los procedimientos realizados, fue posible comprender que la instalación de un SGBD no consiste únicamente en descargar e instalar un programa, sino que también requiere establecer parámetros como las rutas de instalación y almacenamiento, los puertos de comunicación, las credenciales de los usuarios administradores y las herramientas necesarias para su administración.

En el caso de **MySQL**, se pudo comprobar la importancia de configurar correctamente el servidor y establecer una conexión mediante las herramientas destinadas a su administración. De esta manera, se verificó que el motor de base de datos quedara disponible para recibir instrucciones SQL y gestionar la información almacenada. Además, el uso de una interfaz gráfica facilita la administración de las bases de datos y permite visualizar de manera más sencilla los diferentes elementos que conforman el sistema.

Por otra parte, la instalación de **PostgreSQL** permitió identificar de manera práctica las diferentes etapas que intervienen en la configuración de un servidor de bases de datos. Durante el proceso se establecieron la ruta de instalación, el directorio destinado al almacenamiento de los datos, la contraseña del usuario administrador `postgres` y el puerto `5432`. Posteriormente, mediante **pgAdmin 4**, se realizó la conexión con el servidor local, comprobando que el servicio se encontraba funcionando correctamente y que era posible acceder a las herramientas de administración del SGBD.

En conjunto, la práctica permitió reforzar los conocimientos relacionados con la función de los SGBD dentro del desarrollo de software y comprender la importancia de realizar una instalación y configuración adecuada antes de comenzar a trabajar con bases de datos. Tanto MySQL como PostgreSQL proporcionan los mecanismos necesarios para almacenar, consultar y administrar información de manera estructurada, además de ofrecer herramientas que facilitan su utilización. La experiencia obtenida durante esta práctica constituye una base importante para actividades posteriores relacionadas con la creación de bases de datos, ejecución de consultas SQL, administración de usuarios y desarrollo de aplicaciones que requieran persistencia de información.
